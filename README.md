# Projeto de Teste A/B 🚀

## Descrição
Este projeto analisa os resultados de um teste A/B para avaliar o impacto de mudanças na conversão.
Utilizamos Python para limpeza de dados e testes estatísticos.

## Estrutura do Projeto
- `Teste_AB.ipynb`: O código principal com as análises.
- `README.md`: Este arquivo de apresentação.

## Tecnologias
- Python (Pandas, Scipy, Matplotlib)
- Jupyter Notebook
